2. Can You Give Details About Your Current Project?

I currently work on the MedPlus Health Services applications, an internal project for our organization. It is a large-scale application landscape comprising Java, Python, and Node.js applications, including microservices-based architectures.

I am primarily responsible for the DevOps and infrastructure aspects of the project across multiple environments—Dev, QA, Staging, and Production.

Our Dev and QA environments run on on-premises infrastructure. Application servers are hosted on local VMs, and microservices are deployed on a self-managed Kubernetes cluster running on bare-metal servers.

For CI/CD, we use Jenkins. Developers commit code to our Git repositories, and Jenkins handles the build, unit testing, and packaging stages. Application artifacts are stored in Nexus Repository. For microservices, we also build container images and push them to the appropriate container registry.

For Dev and QA deployments, we use an internal deployment automation framework. Development and QA teams can leverage this framework to deploy the required application versions into their respective environments. This approach helps us standardize deployments and minimize manual intervention.

Our Staging and Production environments are hosted on AWS, with infrastructure provisioned and managed using Terraform. We utilize services such as VPC, EC2, EKS, ECR, ALB, RDS, EBS, S3, and IAM, depending on each application's requirements.

We run both traditional applications on EC2 and microservices on EKS. EC2 hosts Java, Python, and Node.js workloads, while containerized microservices are deployed into EKS clusters. Jenkins drives the CI/CD pipeline for both Staging and Production environments.

From an operational standpoint, I handle deployment support, infrastructure troubleshooting, application availability, and environment-related tasks. For our on-premises environments, we use scripts to collect and centralize application logs, enabling development and QA teams to troubleshoot issues efficiently.

Overall, my role covers the complete DevOps lifecycle—infrastructure provisioning with Terraform, CI/CD using Jenkins, artifact management with Nexus, Kubernetes administration, AWS infrastructure management, application deployments, and production support.
